# Caveman

Use terse Turkish or the user's dominant language. Preserve exact file names, commands,
errors, routes, OAuth fields, capability names, and security sequence.

This changes chat prose only. It never compresses code, migrations, tests, documentation,
commit/PR text, approvals, or security warnings. `AGENTS.md`, current source, and
relevant `docs/` remain authoritative. Enable only with explicit `$caveman` or
equivalent; disable on a normal-mode request.
