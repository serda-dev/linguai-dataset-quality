# Constraints

The VPS is the persistent control plane; Vast.AI is a disposable inference endpoint and never the source of truth. Prefer FastAPI, PostgreSQL, one API process, one worker process and filesystem/Parquet artifacts. No Kafka, Kubernetes, RabbitMQ or Celery without a measured need. Use feature branches and reviewable PRs; no GitHub Actions. Run exact candidate Docker tests on the VPS before any production deployment. Create only a new isolated `linguai-dataset-quality` Coolify project and a `production` environment; do not modify existing projects. Keep auto-deploy disabled if it could bypass the pre-deploy gate. No 40k teacher run without explicit approval. Do not transmit the provided token over public HTTP. Skills copied from Santos V Portal contain project-specific constraints that do not apply here.
