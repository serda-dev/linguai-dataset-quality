# Failure recovery

Claim one queued or expired job with `FOR UPDATE SKIP LOCKED`, increment attempt count and give it an expiring random lease token. Commit a validated label and attempt outcome in a single DB transaction only when the lease token still belongs to the caller. An expired worker cannot overwrite another worker's result. Timeout, transport failure, malformed JSON, schema mismatch or wrong document ID records a bounded failure; jobs with attempts remaining can be retried after delay. A crash during remote inference may repeat a billed call; accepted labels are unique and immutable. DB failure pauses worker; readiness fails; no in-memory queue is authoritative. Changing endpoint only affects future calls; attempt provenance records the profile/model used.

For bounded source sampling, resume replays the pinned stream prefix and checks a rolling content digest before processing the next record. The selected top-K set and cursor are committed together for each processed row; a changed prefix fails closed. The label worker inserts an in-flight attempt before sending a teacher request. Expired attempts are marked interrupted on reclaim. Budget errors pause without changing accepted labels.
