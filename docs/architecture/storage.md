# Storage

PostgreSQL tables: `documents` with immutable source coordinates, content hash and text; `labeling_runs`; `jobs` with unique run/document, claim token, lease, bounded attempts; `attempts` with outcome and safe error class, no raw payload; `labels` with unique run/document and full model/profile/prompt/schema/hash provenance; `worker_state` heartbeat. Database initialized by an idempotent schema script for this new, empty project only; future schema changes require explicit migrations. No destructive change is authorized.

ADR 0003 adds an additive migration for run approvals, candidate selection, versioned routes and artifact metadata. `MAX_DATABASE_BYTES` guards both logical original text and current PostgreSQL size under an advisory lock; `MAX_EXPORT_BYTES` and `MIN_ARTIFACT_FREE_BYTES` guard writes. Train-only Parquet uses a temporary file, fsync, checksum and atomic rename. Only exact whitespace-normalized duplicate families are identified; no evaluation split is emitted. External backups/WAL capacity still require measurement on VPS.
