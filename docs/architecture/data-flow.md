# Data flow

Approved source/revision → bounded streaming adapter → immutable document text/hash/identity → sampling decision → explicit labeling run → queued job → worker lease → OpenAI-compatible client with exact system and user prompts → JSON parse/schema and ID validation → transactionally insert attempt/accepted label → separately apply versioned route policy. Failed attempts have bounded retries and no accepted label. Teacher receives no source metadata by default.

Only explicitly configured source mappings enable a generic pinned HF stream. It selects a bounded top-K within a finite scan window, verifies a rolling prefix on resume and publishes jobs after selection completes. Each selected original remains separate from format metadata and teacher observations. The teacher sketch equals the exact original text only within the byte limit; larger texts are rejected pending an approved sketch extraction contract. The train-only export has no evaluation split while near-duplicate policy is unresolved.
